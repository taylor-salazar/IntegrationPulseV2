## Detail of remaining gaps

These are explicitly **not** covered by passing local assertions:

- Full real UI5 routing/DOM/rendering, model-to-control event timing, keyboard focus/accessibility, deep links across BAS rewriting, visual busy overlay preventing double-clicks, FileReader/Fragment lifecycle, and real browser Fetch restrictions. The harness intentionally throws if a test unexpectedly constructs an unstubbed visual control.
- SAP identity truth for multiple normalized/fuzzy/package matches; real destination filtered API support; HTTP 2xx body/task semantics and sender header allowlisting. No assertion that arbitrary first-match resolution is correct in the tenant.
- 24-hour inclusivity/timezones: neither live-mode implementation calculates the advertised count. Existing tests expose absence, rather than pretending a mocked count tests a time window. After approval, implement fixed-clock fixtures exactly before/on/after boundary, with paging and duplicates.
- Duplicate log/message semantics, unknown/ESCALATED status bucket semantics, nonliteral truthy flags, unknown query options and multiple matches require product clarification. Local tests document duplicate payload first-wins and retained catalog duplicates without declaring these product requirements.
- PostgreSQL execution, UUID malformed-input adaptation, expired-row deletion/rollback/connection pool/concurrency, partial database failures, real one-week cleanup and payload ingress authentication. SQL shape and seven-day timestamps are verified only at separate local boundaries.
- Browser wire transport of Unicode/CRLF pulse headers, very large header limits and tenant-specific malformed or unusual-namespace EDMX documents. Standard fixture and malformed XML acceptance are exercised, but regex XML parsing is not a complete parser conformance suite.
- Multi-user/cross-tab review writes and cache tenant changes; review is intentionally local-only. Long notes and storage read/write failures are exercised; optimistic UI failure handling remains inferred.
- Broader Home/Monitoring/Catalog out-of-order loads, timer handle leaks, abort semantics and HTTP response bodies at every possible fallback position are inspected but not exhaustively scheduled. Detail race/destruction and repeated high-impact handlers have deterministic reproducers.
- Browser performance, real network throughput, DB query plans, dependency vulnerability/license scanning, and end-to-end production deployment are outside measured evidence. CI workflow is added but GitHub runner results are not implied by local success.
